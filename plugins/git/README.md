# Git Plugin

**Version:** 0.1.0
**Category:** Workflow
**Status:** 🚧 In Development

## Overview

Git workflow automation including smart commits with conventional commits + gitmoji, PR descriptions, changelog generation, and worktree management.

## Planned Features

### Skills

- **smart-commit** - Generate conventional commits with gitmoji
- **pr-description** - Auto-generate pull request descriptions
- **changelog-generator** - Generate CHANGELOG.md from commits
- **worktree-manager** - Git worktree workflow automation

## Installation

```bash
/plugin install git
```

## Status

This plugin is currently under development. Skills will be added in upcoming releases.
